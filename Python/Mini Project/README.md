# C-DAC BDA Python Data Engineering & Analytics Labs

This repository contains hands-on Python mini-projects completed during the Big Data Analytics (BDA) program at C-DAC.

## Projects Summary
1. **Automated Log Analyzer & ETL Script** (Days 1–3): File I/O, regex parsing, and structured data processing.
2. **E-Commerce Sales Insights Dashboard** (Days 4–7): Data wrangling, aggregation, and EDA using Pandas and Seaborn.
3. **Real-Time Weather/Financial API Pipeline** (Days 8–11): REST API integration, JSON parsing, and relational database storage.

## Tech Stack
* **Language:** Python 3.10+
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Requests
* **Database:** SQLite / PostgreSQL
